# Terminal-Based Calculator

A Python terminal calculator that started as a simple two-number calculator and is being developed into a more complete command-line calculation tool.

The project focuses on building practical Python skills through incremental improvements rather than jumping straight into a complex calculator.

## Current Features

- Basic arithmetic operations
- Addition, subtraction, multiplication, and division
- Modulus (`%`)
- Exponentiation (`**`)
- Input validation for numbers
- Division-by-zero handling
- Custom ASCII terminal interface
- Colored terminal output using Colorama
- Option to perform multiple calculations in one session

## Python Concepts Practiced

- Variables and data types
- Functions
- `while` loops
- Conditional statements
- User input
- Exception handling with `try` and `except`
- String formatting and manipulation
- Working with external Python libraries
- Basic program structure
- Input validation
- Error handling

## How to Run

Make sure Python is installed on your system.

Clone the repository:

```bash
git clone https://github.com/HumaaKhann/Terminal-based-Calculator.git
```

Navigate into the project:

```bash
cd Terminal-based-Calculator
```

Install the required library:

```bash
pip install colorama
```

Run the calculator:

```bash
python project2.py
```
